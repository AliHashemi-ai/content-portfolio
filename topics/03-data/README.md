# 🗂️ Data for AI

Data is what most determines model quality: how training data is collected, filtered, generated and governed.

[← Back to all topics](../../README.md)

## Subtopics

- **Pre-training data**: web crawls, deduplication, quality filtering
- **Fine-tuning data**: instruction datasets, human annotation
- **Synthetic data**: generating and verifying model-made data
- **Data quality & mixtures**: what to keep, how to weight domains
- **Contamination**: keeping benchmark data out of training sets
- **Data governance**: licensing, privacy, documentation
